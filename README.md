从眼前悠闲的小丑鱼出发，跟随它穿过入场通道，进入有珊瑚、沙道、草丛与游鱼的水下世界。张开双手向后推水，靠近藏在礁边的贝壳；也可以停下脚步，抬头看看远处盘旋的巨鲲。

《海底世界》把 **寻找、辨认、观察与挑战** 放在同一次探索里：先读懂本关目标，再选择自己的搜索路线。留意草根间的壳体、沙地上贴底的轮廓，以及开阔水道里的游鱼。任务完成后，还可以在剩余时间里继续寻金，为这一关补上一颗星。

本仓库为 **PICO Unity 2.9.13 / code306** 的公开打包快照，已完成本地构建与校验，沿用 **2.9.11 / code304** 冻结项目的游戏内容与美术输入，并排除关闭排行榜后不用的大字库；本轮不混入 **2.9.12 / code305** 的画质性能候选。云端构建、审核及本次头显佩戴体验仍待验证。当前开放第 **1–20关**；后续关卡显示“未开放，敬请期待”。

## 四章二十关，从拾贝到深海之冠

前五关在最初的礁区认识游泳、抓取和渔枪；第六关起进入 **珊瑚秘境**，穿过天然礁拱，沿沙谷、海草与礁壁继续搜索。四章代表任务进程，并非四张独立地图。开放关卡可从菜单直接选择，也适合按顺序慢慢熟悉这片海。

| 篇章 | 你的探索重点 | 隐藏金币与章末挑战 |
| --- | --- | --- |
| **第一章 · 初识海洋**<br>第1–5关 | 从五种贝壳开始，进而收齐十种；认识贝壳与目标鱼的混合收集，在第4关辨认四种指定鱼。 | 每关1枚金币。第5关不限时：找到渔枪，对任意一条鲨鱼单独累计命中10次，再靠近抓取。 |
| **第二章 · 珊瑚迷踪**<br>第6–10关 | 在珊瑚秘境探索河豚、海马与贴底的比目鱼；第8关按顺序收鱼，留意草丛和背光礁隙。限时从18分钟收紧到15分钟。 | 每关2枚金币。第10关还需完成贝壳、鱼类目标，并对一条鲨鱼累计命中11次后抓取。 |

鲨鱼挑战均有 **20发共享弹药**，多条鲨鱼的命中数分别计算。达到要求后仍要近距离抓取；如果最后一发已经让某条鲨鱼满足要求，仍保留抓取机会。放松射击手势即可隐藏渔枪，继续划水寻找合适的接近方向。

**通关与寻宝是两层目标：**完成本关全部主目标获得 **★★**；再收齐本关隐藏金币获得 **★★★**。只找到金币不会直接通关。第20关完成后可以继续探索、重玩或退出，不会进入未开放的第21关。

## 为喜欢海洋的你，留一本慢慢填满的收藏册

**拾起看得见的收获。** 十种贝壳有各自的形状：扇贝的放射纹、海螺的螺旋、蛏子的细长壳体，以及带棘饰的骨螺。它们和十种关卡目标鱼构成收集玩法；本关缺什么，随时打开目标面板查看。海里也有营造氛围的游鱼，并非每条可见的鱼都是本关抓取目标。

**观察，也是一种进度。** 张开手，用手势射线稳定指向近距离生物约 **2秒**，观察金环完成后记录发现，解锁名称、简短说明、栖息线索与模型预览。当前图鉴提供 **30类可观察记录**，包含鱼类、海龟、海豚、珊瑚和贝壳外形；它不是“30种鱼”，也不把模型分类当作精确的生物学鉴定。部分记录随关卡逐步出现，稀有类别需要留意礁隙、草丛或开阔水道。

**把探索积累成自己的履历。** 观察记录、收藏与历史最佳星级跨关保留。第一次拾贝、收齐十种贝壳、完成海洋观察、找到隐藏金币、首次三星或捕获鲨鱼，都有对应的本地成就进度。重玩可以挑战更多三星、补齐漏掉的观察记录；重新开始本关会重置这一轮目标，不会清除已有收藏和历史荣誉。未开放后续内容所需的成就仍保留规划与旧记录，不代表现在已经可以全部完成。

找到隐藏金币时，金光与金币喷涌为这次收获庆祝。越往后的关卡，金币越多；想拿到三星，就需要在完成主目标之外再认真检查一次自己的路线。

## 一分钟上手

新档首次进入第1关有四步教学：**张手保持 → 划水并停下 → 握抓练习扇贝 → 打开菜单查看目标**。动作保持自然，让双手处在头显能够看到的位置；不必急着连续用力划动。菜单中的舒适设置可调整速度、人工转向与音量，也可重看教学。

| 想做什么 | 怎么操作 |
| --- | --- |
| 向前游 | 张开双手，向后推水；回手后再划下一次 |
| 转向与上浮 | 用单手划水辅助转向；抬头并向下推水可向上探索 |
| 抓取贝壳、金币或目标鱼 | 手掌靠近目标，先张开再握拳 |
| 记录生物观察 | 张开手，用手势射线稳定指向6米内的可观察生物约2秒 |
| 打开菜单 | 用手势射线指向上方任务条，高亮后捏合 |
| 使用渔枪 | 先拾取，再摆出手枪姿势；弯曲食指单发射击 |
| 查看收藏与目标 | 在菜单中打开本关目标、生物图鉴、收藏和成就 |

抓取需要近距离接触且没有礁石遮挡。一次握抓只处理一个目标；下一次先松手，再握。食指持续弯曲不会连发，需先伸直再扣动。菜单打开时暂停移动和任务计时，收起后继续探索。

## 如何打包

PICO 云端执行 `:launcher:assembleRelease`，直接使用本仓库预编译的原生库，不重新编译 IL2CPP。Unity 生成的 Gradle 模板及工具路径保留原样，平台按其文档处理本机 Unity 安装路径。

本机复核时使用对应 Unity 的 Android 工具链，显式设置 `ANDROID_HOME` 和 `ANDROID_SDK_ROOT`，再以其 Gradle 执行：

```sh
gradle :launcher:assembleRelease --console=plain --no-daemon
```

`gradle` 须指向 Unity 自带版本。若导出模板没有 `gradlew`，不要从其他版本复制 wrapper 来替换；使用该 Unity 安装中的 Gradle launcher。详细原生清单及 SHA256 见 `.vibelab-prebuilt.json`。

修改 C#、资源或 Unity 配置时，请回到源码工程重新正式导出和预编译，再更新此仓库；不要用旧原生库搭配新 metadata，也不要启用会生成 DummyBinary 的 `skipIl2CppBuild`。
