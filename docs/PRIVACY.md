# 安全与隐私检查范围

当前发行版本关闭在线排行榜和昵称编辑入口；游戏进度、收藏及成就继续使用本地存储。重新启用在线服务时，应单独配置服务端审核、用户告知和数据管理能力。

发行仓库及打包材料不得包含开发者的生产服务器地址、部署密码、访问令牌、私钥或私有部署配置。仅删除当前文件不足以清理已经提交的内容，历史分支、标签、提交对象和二进制资源也需要检查。SDK 官方文档、第三方公开资源地址及测试占位地址与生产配置分别识别。

检查覆盖源码和配置、Git 全部本地对象及引用、LFS 实际资源，以及打包后的 Unity 数据与编译元数据。已知生产地址按多种字符编码匹配，APK 和常见压缩容器展开后检查；凭据模式命中需人工区分测试数据、文档示例和真实敏感信息。发布前应在最终提交与最终 APK 上重新验证。

历史净化不能撤回他人已经下载的克隆或安装包，也不能承诺托管平台缓存的旧提交立即消失。若真实凭据曾经泄露，移除历史不能替代作废和轮换。模式扫描也不能保证发现任意未知、加密或刻意混淆的信息。

本说明描述检查方法和边界，不代表所有设备体验、网络抓包或平台审核均已完成。
